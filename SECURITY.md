# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.3.x   | :white_check_mark: |
| < 1.3   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in the VerScript language compiler, runtime, or official IDE applications, please report it via private disclosure rather than opening a public issue.

- **Email**: `security@verscript.org` (or directly via GitHub Private Vulnerability Reporting on the repository).
- Please include steps to reproduce, a proof of concept script (`.vrs`), and the affected architecture/operating system.
- We aim to acknowledge reports within 48 hours and provide a patch/remediation within 14 days.
